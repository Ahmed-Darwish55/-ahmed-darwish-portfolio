# Ahmed Darwish — 3D Portfolio

بورتفوليو تفاعلي ثلاثي الأبعاد مبني بـ **React + Vite + Three.js (R3F) + GSAP**، بيحكي رحلتك من **الجيزة → الدمام**، وبيدعم **إنجليزي/عربي** مع RTL كامل.

---

## التشغيل

```bash
npm install
npm run dev          # سيرفر تطوير على http://localhost:5173
npm run build        # نسخة الإنتاج في مجلد dist/
npm run preview      # معاينة نسخة الإنتاج
```

## الرفع (Deploy)

**Vercel** (نفس مكان بورتفوليوك القديم):

```bash
npm i -g vercel
vercel            # أول مرة
vercel --prod     # للنشر النهائي
```

أو من واجهة Vercel: اربط الريبو، والإعدادات تتظبط لوحدها
(`Framework: Vite` · `Build: npm run build` · `Output: dist`).

يشتغل كمان على Netlify / GitHub Pages من غير أي تعديل (`base: './'` متظبط في `vite.config.js`).

## نظام التصميم

`src/styles.css` مرتّب في ١٤ قسم مرقّم، وكل شيء بصري بيتحدد من توكنز في `:root`:

```css
--fs-display / --fs-h1 / --fs-h2 / --fs-h3 / --fs-lead / --fs-body / --fs-meta / --fs-micro
--s-1 … --s-10        /* سلّم مسافات أساسه 4px */
--r-xs … --r-pill     /* أنصاف الأقطار */
--teal --gold --cyan --violet   /* لكل لون وظيفة واحدة */
```

**سياسة الألوان** — لكل لون شغلة واحدة بس:

| اللون | الوظيفة |
|---|---|
| `--teal` | التفاعل، الأزرار الأساسية، الحالة الحيّة |
| `--gold` | التكريم والجوائز فقط |
| `--cyan` | الجغرافيا، الرحلة، التوأم الرقمي |
| `--violet` | المساعد الذكي فقط |

## السجلّان: SCENE و SHEET

الصفحة فيها نوعين من الأقسام، وده اللي حلّ مشكلة النص اللي كان بيتزاحم مع المشهد ثلاثي الأبعاد:

**SCENE** (`.section--scene`) — hero · journey · origin · station · contact.
المشهد ثلاثي الأبعاد هو البطل، والنص قاعد على **زجاج** (`.panel` / `.route__item` / `.contact__card`)
بجنبه. ارتفاع كل قسم `100svh`.

**SHEET** (`.section--sheet` جوّه `<div className="sheet">`) — award · work · twin · stack · proof.
دي **ورقة مسح** معتمة متصلة: أرضية واحدة بتتلاشى من فوق ومن تحت، عليها شبكة graticule.
المشهد ثلاثي الأبعاد **مش موجود** وراها خالص — فمفيش `scrim` ولا `text-shadow` ولا `backdrop-filter`
عشان النص يبان. القراءة بتحصل على أرض صلبة.

الزجاج معرّف مرة واحدة في القسم ٠٦ من `styles.css`، وبيتحوّل أوتوماتيك لأرضية معتمة على الموبايل
(كل `backdrop-filter` ده pass كامل على الـGPU) ولو المستخدم مفعّل «تقليل الشفافية».

## الفهرس الجانبي (Rail)

على الشاشات ≥1100px، أقسام الموقع العشرة بتظهر كعمود أرقام على حافة الشاشة (`.nav__links`)،
والاسم بيتفتح عند الـhover أو لما القسم يبقى نشط. تحت كده بيرجع منيو burger عادي.
الـrail **شقيق** للـ`<header>` مش ابنه — لأن الـheader عليه `mask-image` والـmask بيقص أي عنصر
`position: fixed` جوّاه.

## المساعد الذكي (Ask)

زرار بنفسجي تحت-يمين، أو دوس `/` من أي مكان. بيجاوب على أي سؤال عن أحمد **من بيانات الموقع نفسها**.

```
src/ai/kb.js      → يبني قاعدة معرفة من content.json + site.json + public/data/cv.txt
src/ai/search.js  → ترتيب BM25 ثنائي اللغة (بيطبّع العربي: تشكيل، ألف، ياء، تاء مربوطة)
src/ai/answer.js  → قواعد نيّة (تواصل، خبرة، مهارات، مشاريع، جوائز، توفّر…) + رجوع للبحث
src/components/Ask.jsx → اللوحة
```

**محرّكان خلف نفس النداء:**

1. **محلي (افتراضي)** — كل شيء في المتصفح. مجاني، شغال أوفلاين ومن `file://`، و**مستحيل يخترع
   معلومة** لأن كل كلمة بيرجّعها طالعة من الـJSON.
2. **LLM (اختياري)** — لو حطيت رابط في `public/data/site.json`:

   ```json
   "assistant": { "endpoint": "https://ahmed-assistant.<you>.workers.dev" }
   ```

   بيبعت السؤال + السياق المسترجع لـCloudflare Worker (`worker/assistant.js`) اللي مخبّي مفتاح
   الـAPI. لو الـWorker وقع أو اترفض، اللوحة بترجع للمحرك المحلي من غير ما الزائر يحس.
   التفاصيل في `worker/README.md`.

**عشان تغيّر اللي بيعرفه:** عدّل `public/data/content.json` أو `site.json` أو `cv.txt` وبس.
مفيش أي معلومة مكتوبة جوّه كود المساعد.

## هيكل المشروع

```

├─ site.js                ← تحميل الملفين + التحقق (validate) + الدمج (merge)
├─ store.js               ← الحالة + هوكس المحتوى (useUI / useProfile / useStations)
├─ styles.css             ← التصميم كله + نظام الأطلس الكارتوغرافي
├─ data/land.json         ← نقاط اليابسة للكوكب (مولّدة بـ scripts/bake-land.mjs)
├─ three/
│  ├─ Scene.jsx           ← الكانفاس + حركة الكاميرا لكل مرحلة
│  ├─ MorphField.jsx      ← محرك الجسيمات + الشيدر + خريطة المراحل
│  ├─ JourneyLayer.jsx    ← الغلاف الجوي + قوس الرحلة + علامات المدن
│  └─ shapes.js           ← مولّدات الأشكال (كوكب، أهرامات، أفق، شبكة، ميدالية، اسم)
└─ components/
   ├─ Sections.jsx        ← الهيرو · الرحلة · الموطن · الدمام · تواصل
   ├─ Atlas.jsx           ← الجائزة · دراسات الحالة · التوأم الرقمي · الطبقات · التكريم
   └─ Loader · Nav · Cursor · Reveal · Lightbox · DataError
```

## 🧭 الفكرة: الأطلس + الطبقات

الموقع مبني على محورين:

**المحور الأفقي — الرحلة:** الجيزة ← الدمام. جغرافيا حقيقية بتحكي المسار المهني.

**المحور العمودي — الطبقات:** كل واجهة GIS حقيقية هي طبقات فوق بعض. ده بالظبط
شغلك اليومي، فبقى هو نموذج عرض المهارات:

```
Z00  Spatial UX          ← اللي الناس بتلمسه
Z01  Frontend            ← Angular · React · TypeScript
Z02  3D / Immersive      ← Three.js · Unity · VR
Z03  GIS                 ← ArcGIS · Experience Builder
Z04  Data                ← المؤشرات ولوحات التحكم
```

في قسم «الطبقات» فيه زرار **«افصل الطبقات»** بيباعدهم في العمق (3D) وبعدين
بيرجّعهم يندمجوا. الرسالة: *«مش خمس مهارات منفصلة — خمس طبقات لنظام واحد.»*
كل طبقة تحتها لينكات لدراسات الحالة اللي بتثبتها.

## 🖼️ الصور المؤقتة

دراسات الحالة الخمسة فيها صور SVG مؤقتة في `public/media/` (١٨ كيلوبايت للخمسة).
كل واحدة مكتوب عليها **PLACEHOLDER** وبيظهر عليها تاج «صورة مؤقتة».

عشان تبدّلها بلقطة حقيقية:

1. حط الصورة في `public/media/` (مثلاً `geo2d-real.png`)
2. في `public/data/site.json` غيّر: `"image": "./media/geo2d-real.png"`
3. شيل `"placeholder": true`
4. **Refresh — من غير build.**

التوأم الرقمي بيستخدم صورك الحقيقية أصلاً (`forum-vr.jpg` وإخواتها).

## ⚡ الأداء

- **backdrop-filter:** ١٦ عنصر على الديسكتوب → **٤ بس على الموبايل** (بيتبدلوا بخلفية صلبة).
- **الصور:** `loading="lazy"` + `decoding="async"` — ٤ صور بس بتتحمّل في البداية.
- **أول تحميل:** ‎0.39 ميجا · FCP أقل من ثانية.
- **الجسيمات:** بتتظبط أوتوماتيك حسب الجهاز (`?q=low` / `?q=high` للتجربة اليدوية).
- `prefers-reduced-motion` و`prefers-reduced-transparency` مدعومين.
